## 9 · Packaging procedure for a new chapter

1. Write `text/chNNN.xhtml` from the ch276/277 header template: `<?xml?>`, DOCTYPE, both
   stylesheet links, `chapter-header` (spelled-out number + title), then blocks.
2. `content.opf`: `<item>` + `<itemref>` after the last chapter; bump both `dc:` strings.
3. `toc.ncx`: next `num_N`/`playOrder` (chapters + 2), contiguous.
4. `text/nav.xhtml`: one `<li>`. `cover.xhtml`: "Chapters 1–N". `glossary.xhtml`: footer N.
5. `characters.xhtml`: extend bios (never replace); add a card only for a major recurring
   figure. New named figure in a chapter ⇒ `char-intro-block` in-text + one `<item>` per image.
6. Gate, build, then verify inside the ZIP (hash match, spine tail, navPoint count, title
   strings) — the archive check is what actually proves the package.
